# myIdealism
我心中的唯心主义，以及那位祂。

## 核心
我的心中的唯心主义，以及那样一位祂。祂是一位神明，讲“神明”仅以概念，而可能非人、非生物、更非物。祂创造了基石，而我的思想在运转这个世界。

我的生命，运转在一具肉体上；我的思想，运行在一个意识体上。这样一个基本意识体加上一具肉体，组成了我。

宇宙之大，到尘埃之小，世间万物所有规律皆由祂而创造，祂可能非人、非生物、更非物。

而世界的运转又由我的存在而存在。那所有的信息的辐射都在我的意识之中维持不息，是我的观念与意志。

其他的人们、物们，同时存在，他们也由祂而创造。并伴随我、依附我。

如此其他多的由我所知的、人们所信仰的。概括而论的他们的信仰……是我承认存在的理念，因为这是一些人们的信仰，但不是我认同的理念，或有同道见解。
